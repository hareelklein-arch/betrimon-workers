# החלטות אפיון מאושרות

מסמך זה נועל את שלוש ההחלטות מהאפיון. אין לשנות אותן בלי דיון מפורש. בשלב זה אין קוד אפליקציה.

## ADR 1 — ארכיטקטורה: Vercel + Next.js + Supabase Postgres

סטטוס: **מאושר**

- **המידע** יושב ב-PostgreSQL מנוהל ב-Supabase, אזור `eu-central-1` (פרנקפורט).
- **הקוד** יושב בריפו Git הזה (`betrimon-workers`), כאפליקציית Next.js + TypeScript עם ממשק PWA בעברית RTL.
- **הריצה** היא בענן: Vercel מריץ את המסכים וה-API, Supabase מריץ מסד, Auth ו-Realtime. אין שרת פיזי ביישוב ואין אחסון ב-Excel כמקור אמת.

לא נבחר: Firebase, Google Sheets, Cloudflare Workers/D1 כברירת מחדל, או VPS לניהול עצמי.

## ADR 2 — התראות: Web Push בגרסה 1, וואטסאפ אחר כך

סטטוס: **מאושר**

- גרסה 1: התראות בתוך האפליקציה (טבלת `notifications`) ו-Web Push לטלפון.
- בקשת החלפה שולחת התראה לכל העובדים הפעילים.
- אישור החלפה שולח התראה **רק למבקש**, כולל מי אישר.
- וואטסאפ הוא שלב 2 (ספק חיצוני ותשלום נוסף), לא חלק מגרסה 1.

## ADR 3 — היקף שכר: שעות × תעריף אחרי אישור מנהל

סטטוס: **מאושר**

- עובד מדווח שעות; מנהל מאשר או דוחה. בלי אישור אין שכר.
- החישוב: שעות מאושרות × תעריף רלוונטי = **ברוטו לתשלום**.
- תעריף יכול להיקבע לפי סוג עבודה, גיל, או עובד ספציפי.
- בסוף חודש המנהל נועל תקופה ומפיק דוח (כולל ייצוא Excel).
- גרסה 1 **לא** מחשבת מס, ביטוח לאומי, ניכויים, או תלוש רשמי.
